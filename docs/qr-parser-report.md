**Conclusion:** cartons and boxes share product details only (article, colour, MRP, size within range, and on compact labels the 4-digit code). No serial, code or reference on a carton appears on any box in its group, and vice versa. The labels therefore cannot prove which boxes were inside which carton. The carton module must treat carton contents as *expected* (from the approved assortment), never as verified box-level stock.

## 9. Differences from the previous parser

- Old parser rejected 1 real box label(s): `RH0005G`. The new parser reads all 42.
- Old parser misread 0 label(s).
- Old parser took the division from any F/L/P/S letter anywhere in the first field. The new parser does not assign a division at all; the article master does.
- Old duplicate check compared raw text, so URL-wrapped and plain scans of the same box were two different boxes. The new key is the normalised payload.
- Old parser could not read carton labels at all (they were "invalid"). The new parser recognises both carton layouts, so the box scanner can tell the user it is a carton, and the carton module can reuse the same parser.

## 10. Assumptions that still need confirmation

1. **Carton pack letter** (`A` in every compact sample). Is it an assortment / packing code? If yes, the assortment master may need to be keyed by article + size range + this letter.
2. **Carton date**: packing date or manufacturing date? In 5 of 7 groups it falls in the same month as the box manufacturing month; in 2 it is 2 months later.
3. **4-digit code** (1004, 1005, 1006, 1010, 1011, 1001, 1008) and the matching **R-code** on boxes: plant or unit? Not needed for stock, kept for traceability.
4. **MA0 / MA1 / MA2** on box labels: meaning unknown; kept.
5. **9-digit reference** on EAN-bearing box labels: meaning unknown; kept.
6. **Hyphen-format carton tail**: the split between the 5-character code and the serial is uncertain (CU0025G labels give an 11-digit serial with this split). Duplicate detection uses the whole payload, so this does not affect correctness.
7. **Compact carton article code is 7 characters** in every sample. A longer code would shift the colour code; the carton module must validate the result against the article master before trusting it.
8. **Box serial uniqueness**: confirmed by Shayona for individual boxes. The rising serial across divisions suggests one global label counter; not relied on.
